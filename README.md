### 🚀 Featured Projects

#### 🛡️ **SentinelX – ML & Graph-Based Security Operations Center**

**Overview:** SentinelX is my BE Major Project focused on building a practical Security Operations Center (SOC) platform for advanced threat detection and intelligent incident investigation.

The system combines **rule-based detection, machine-learning anomaly detection, graph-based alert correlation, threat intelligence, MITRE ATT&CK mapping, risk scoring, and RAG-based investigation assistance**.

**Key Areas:**
* 🔍 **Detection Engine** – Rule-based detection for suspicious activities such as brute-force attempts, privilege escalation, malicious PowerShell activity, and malware indicators.
* 🤖 **ML Anomaly Detection** – Isolation Forest-based anomaly detection for identifying unusual telemetry.
* 🕸️ **Graph-Based Correlation** – BFS/DFS-based alert correlation for connecting related security events.
* 🎯 **Risk Scoring** – Risk evaluation using severity, asset criticality, IOC reputation, MITRE ATT&CK relevance, and confidence.
* 🧠 **Threat Intelligence** – Threat actor profiling, IOC analysis, and security intelligence workflows.
* 🔎 **Threat Hunting Workspace** – Search and filter raw telemetry by IP, port, protocol, and other event attributes.
* ⚙️ **Dynamic Detection Rules** – CRUD-based rule management with Sigma-inspired detection logic.
* 📚 **RAG Investigation Assistant** – Retrieval-Augmented Generation workflow for investigation support.
* 📊 **SOC Dashboard** – Centralized visibility into alerts, incidents, risk, intelligence, and investigations.

**Tech Stack:** Python • FastAPI • React • MongoDB • PostgreSQL • Redis • Scikit-learn • Graph Algorithms • RAG • Groq • MITRE ATT&CK • REST APIs

**Repository:** [AmiteshJ/SentinelX](https://github.com/AmiteshJ/SentinelX)
